IT-Begriffe einfach erklärt

Viele Wörter aus der IT klingen erst einmal kompliziert. Hier findest du die wichtigsten Begriffe in einfacher Sprache.

Code
Anweisungen, die ein Mensch für den Computer schreibt – wie ein Rezept, das der Computer Schritt für Schritt befolgt.
Programmiersprache
Eine Sprache, mit der man dem Computer sagt, was er tun soll, z. B. JavaScript oder Python.
Browser
Das Programm, mit dem du Webseiten öffnest, z. B. Chrome, Firefox oder Edge.
HTML
Baut das Gerüst einer Webseite: Überschriften, Texte, Bilder und Links.
CSS
Sorgt für das Aussehen einer Webseite: Farben, Schriften, Abstände und Anordnung.
JavaScript
Macht Webseiten interaktiv – zum Beispiel ein Button, der etwas aufklappt.
Git
Ein Werkzeug, das alle Änderungen am Code speichert. So kann man jederzeit zu einer älteren Version zurück.
Repository
Ein Projektordner, den Git verwaltet. Auf GitHub kann ein ganzes Team darauf zugreifen.
Commit
Ein gespeicherter Zwischenstand mit einer kurzen Beschreibung, was geändert wurde.
Bug
Ein Fehler im Programm. Das Finden und Beheben nennt man „Debugging“.
Cloud
Computer und Speicher im Internet, die man nutzen kann, ohne sie selbst zu besitzen.
Consulting
Beratung: Unternehmen holen sich Experten, die ihnen helfen, Probleme zu lösen – oft mit Technologie.

Kein Begriff gefunden. Versuch es mit einem anderen Wort.

Softskills, die du kennenlernst

Im Beruf zählt nicht nur Fachwissen. Diese Fähigkeiten üben wir im Praktikum gemeinsam.

Kommunikation

Klar und freundlich ausdrücken – im Video-Call, im Chat und per E-Mail.

Teamarbeit

Aufgaben aufteilen, sich gegenseitig helfen und gemeinsam ans Ziel kommen.

Präsentieren

Ergebnisse verständlich vorstellen und vor anderen sicher sprechen.

Zeitmanagement

Aufgaben planen, Prioritäten setzen und Fristen einhalten.

Feedback

Konstruktive Rückmeldungen geben – und selbst daraus lernen.

Problemlösung

Große Aufgaben in kleine Schritte zerlegen und kreativ Lösungen finden.
